Чтобы запустить проект необходимо выполнить следующие команды: 

docker build -t testservice .

docker run --rm -p 8080:8080 --name testservice testservice

-----------

Дальше в сваггере сначала необходимо зарегистрировать пользователя.
При регистрации ожидается выбор роли:
0 - Юзер
1 - Админ

Дальше будет выданы токены
-------------

После чего можно проводить CRUD операции с нодами
